# Initial setup note for the demo

This is deliberately incomplete sample work for the revision scene, not the full project guide.

Install the pinned packages, start the local Anvil chain and start the workspace:

```sh
npm ci --ignore-scripts
npm run chain
npm start
```

Open http://127.0.0.1:4321. The note does not yet explain what to do when a transaction is interrupted. In the demo, the client asks for that missing section and the next delivery links to the full setup guide.
