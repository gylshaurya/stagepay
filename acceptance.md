# Local workspace acceptance

- Create a project with up to three milestones and fund the actual local escrow with freely minted DEMO tokens.
- Persist scope, milestone names, evidence and receipt history across service restarts.
- Switch clearly labelled local demo roles; client and freelancer actions follow contract permissions.
- Join the agreement, submit evidence, request revision without payment, accept once, and withdraw the exact credit.
- Propose and mutually accept a scope change. Accepted work stays paid; unpaid evidence resets.
- Raise a dispute and mutually settle remaining funds. Show indefinite lock risk before funding.
- Display transaction hash, chain, result and scope/evidence hashes without claiming public testnet deployment.
- Validate input, block cross-origin writes, bind only to loopback, reject stale project versions and stop after uncertain chain actions until reconciliation.
- Network settings show live local connection and unconfigured Sepolia explicitly. No signing secrets or private keys in env files.
- Desktop/mobile layout, keyboard forms, empty/loading/error states and readable copy.
